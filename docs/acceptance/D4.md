# D4 acceptance evidence

**Status: IMPLEMENTED; browser smoke and production container build not verified in this workspace.** No deployment was performed.

## Automated evidence

The feed query runs against the product Video read model through the service-role-only `read_feed_page` SQL function. It joins only channels followed by the authenticated user, orders by `published_at DESC, video_uid DESC`, applies a tuple keyset cursor, and returns one extra row to determine whether another page exists. The query includes only available cached summaries; missing summaries use `not_requested`. It has no provider adapter dependency and never calls inference.

`tests/rls.integration.test.mjs` applies the D1, D3, and D4 migrations in PGlite and verifies:

- a user sees only videos from their followed channels;
- equal publication times use descending `video_uid` as the stable tie-breaker;
- the cursor continues after the exact `(published_at, video_uid)` boundary without duplicates;
- a channel filter cannot expose a channel the user does not follow;
- a new account returns no feed rows;
- only available cached summaries are projected, while missing summaries are `not_requested`;
- anonymous and authenticated browser roles cannot call the privileged feed RPC.

`tests/feed.test.mjs` verifies cursor validation/round-tripping, 20/50 pagination bounds, authenticated API behavior, session-user scoping, and bounded error responses.

## UX evidence and limits

Feed cards render channel/title/publication time/duration/thumbnail/availability, cached summary content or a non-generating summary state, and a YouTube link. Channel filtering and Load more use the `/api/feed` contract. The feed card switches to a stacked layout below 620px; the shared content shell is capped at 860px and supports 320px minimum viewport width.

An authenticated browser pass at ~375px and desktop width was not available: this workspace has no configured Supabase session, and Docker is not installed. The D3 report records its separate Node 24 Docker build/health check. No live provider call or deployment was performed for D4.

## Deliberate exclusions

No summary generation, usage charging, summary polling, background synchronization, scheduler route, populated demo feed, or billing. Feed reads display cached available summaries if present, but opening or paging the feed never triggers a provider call.
